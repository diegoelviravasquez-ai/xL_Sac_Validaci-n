# Entrega para Ana — EMMA · SAC

Paquete web para la valoración experta de **Ana García-Valcárcel**.
Punto de entrada: **`index.html`**.

## Archivos
- `index.html` — portada / entrega (empieza aquí). Lleva el bloque "Lo que te pido".
- `FLUJO_EMMA_estilo_Apple.html` — el ciclo EMMA (alumno → docente → materiales).
- `SAC_explicado_metodo_estilo_Apple.html` — el método y los fundamentos.
- `EMMA_x_DUA_crosswalk_estilo_Apple.html` — crosswalk DUA (3 principios, 9 pautas).
- `IMPLEMENTACIONES_EMMA_estilo_Apple.html` — por rol, marcos y cómo evalúa.
- `GUIA_evaluacion_Ana_estilo_Apple.html` — la rúbrica (9 áreas, con casillas).
- `CARTA_valoracion_borrador_Ana.html` — guía para su carta de valoración (+ texto opcional).
- `portada.html` — la aplicación (demo interactivo).
- `taller_autonomia_v8_Ana.html` — el taller de autonomía.

Todo es HTML estático, sin dependencias: funciona offline abriendo `index.html`.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube **todos** estos archivos a la raíz.
2. En el repo: **Settings → Pages**.
3. En *Build and deployment → Source* elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En 1–2 minutos tendrás la URL pública: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`
   Esa es la que le pasas a Ana (abre directamente en la portada).

> Si quieres que no sea público mientras lo revisas, crea el repo como **privado**;
> GitHub Pages seguirá sirviéndolo solo a quien tenga el enlace una vez activado.
